# Floating Ticker TW

一個基於 PyQt6 的台灣股票桌面懸浮行情元件，預設顯示 `0050`，透過台灣證券交易所 MIS 公開介面取得即時價格、漲跌幅、當日高低點。

## 功能

- 無邊框、可拖曳、可置頂的桌面懸浮窗
- 預設股票代號 `0050`
- 支援上市（TWSE）與上櫃（TPEx）股票代號
- 每 5 秒自動更新行情，不需要 API Key
- 價格變化時綠色／紅色閃爍提示
- 價格和漲跌幅使用固定欄寬，更新時不會抖動或縮放
- 右鍵設定並儲存最多 10 個股票代號
- 資料平台名稱與 Logo 已移除
- 淺色、深色、跟隨系統三種主題
- HTTP 代理設定
- 右鍵選單切換股票、主題、代理和離開
- 關閉後儲存視窗位置、股票代號、主題和代理設定
- TW 版使用獨立的 `FloatingTickerTW/Ticker` 設定命名空間，不會讀取或覆蓋原版設定

## 安裝

需要 Python 3.10 或更新版本。

```bash
pip install -r requirements.txt
```

## 執行

```bash
python main.py
```

## 操作方式

- 左鍵拖曳視窗
- 右鍵開啟選單
- `切換股票`：從已儲存的 10 個股票代號中選擇
- `輸入股票代號...`：輸入新的上市或上櫃股票代號
- `股票代號設定（10個）...`：編輯預設儲存的 10 個代號
- `外觀`：跟隨系統、深色、淺色
- `代理設定`：設定 HTTP 代理
- `視窗置頂`：切換置頂狀態
- `離開`：關閉程式

## 代理設定

也可以使用環境變數：

```powershell
$env:HTTPS_PROXY = "http://127.0.0.1:7890"
python main.py
```

支援 HTTP 與帶認證的代理位址：

```text
http://user:password@127.0.0.1:7890
```

## 資料來源

行情來自台灣證券交易所 MIS 公開查詢介面 `mis.twse.com.tw`，程式同時查詢 `tse_代號.tw` 與 `otc_代號.tw`，不需要 API Key。
